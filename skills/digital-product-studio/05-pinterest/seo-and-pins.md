# Pinterest Marketing (Module 05)

## Deep SEO Requirements
You must research keywords online (Pinterest autocomplete, Trends, competitor pin titles).

### Keyword Placement (2026 best practices)
- Pin title: Primary keyword + buyer modifier first (printable, template, editable). Front-load within first ~40 characters. Max 100 characters.
- Pin description: Natural language, primary keyword in first sentence, 1–2 related phrases. 200–500 characters ideal. Max 800.
- On-image text: Primary keyword + benefit, readable at ~236px thumbnail width. Pinterest OCR reads it.
- Alt text: Descriptive + keyword.
- Board: Keyword-named board suggestion.

### Pin Formats to Rotate (15–20 total)
1. Benefit Headline + Product Mockup
2. Inside the Product Preview
3. List / Number pin
4. Before / After or Problem → Solution
5. Sandwich layout (photo + title band)
6. What's Included
7. Freebie vs Premium comparison
8. Feature spotlight
9. Lifestyle / tablet mockup

### Specs
- Standard pins: 1000 × 1500 px (2:3)
- High contrast, solid text bands, one focal point
- Elevate (do not replace) any existing aesthetic

Generate distinct concepts. Provide design directions + SEO fields for each.
